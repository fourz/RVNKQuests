## 🎯 Learning Paths

### New Developer Onboarding

```
Day 1 (30 minutes):
├─ Read: QUICK_START.md (5 min)
├─ Read: ARCHON_TRAINING_GUIDE.md (15 min)
└─ Review: AGENT_ROLE_DESCRIPTIONS.md (10 min)

Day 2 (Start working):
├─ Get task from Archon
├─ Review: ARCHON_TRAINING_GUIDE.md (reference as needed)
└─ Execute: Task-driven development cycle
```

### Existing Developer Reference

```
When you need to:
├─ Remember the workflow? → QUICK_START.md
├─ Work with agents? → AGENT_ROLE_DESCRIPTIONS.md
├─ Check your progress? → ARCHON_TRAINING_GUIDE.md (checklist section)
└─ Help a new developer? → Share QUICK_START.md
```

### Agent Coordination

```
When assigning work to agents:
├─ Choose agent? → AGENT_ROLE_DESCRIPTIONS.md (decision tree)
├─ Write clear task? → AGENT_ROLE_DESCRIPTIONS.md (communication patterns)
├─ Track progress? → Reference ARCHON_TRAINING_GUIDE.md (workflow)
└─ Review deliverables? → AGENT_ROLE_DESCRIPTIONS.md (turnaround times)
```

## 🚀 Quick Start for New Developers

1. **Read QUICK_START.md** (5 min)
   - Understand the basic workflow
   - Get your first task from Archon

2. **Read ARCHON_TRAINING_GUIDE.md** (15 min)
   - Deep dive into each phase
   - Understand the detailed process

3. **Reference AGENT_ROLE_DESCRIPTIONS.md** (as needed)
   - When you need agent help
   - How to request and track work

4. **Start Your First Task**
   - Follow the workflow from guides
   - Reference guides as needed
   - Ask for help if stuck

## 💡 Tips for Using These Guides

### As a New Developer
- Read QUICK_START.md first, don't skip it
- Have ARCHON_TRAINING_GUIDE.md open while working
- Reference AGENT_ROLE_DESCRIPTIONS.md when asking for agent help

### As a Team Lead
- Point new hires to QUICK_START.md
- Have them read ARCHON_TRAINING_GUIDE.md on day 2
- Use AGENT_ROLE_DESCRIPTIONS.md for task assignment

### As an Agent User
- Review AGENT_ROLE_DESCRIPTIONS.md before assigning work
- Use communication patterns from the guide
- Check expected turnaround times
