### Creating New Reports

When creating a new report:
1. Choose appropriate type (status/completion/validation)
2. Follow report naming convention
3. Include key sections (summary, findings, recommendations)
4. Link to related documents
5. Date the report clearly
6. Save in docs/reports/ directory
